# Antigravity task — Inspect, run, debug and integrate a module ZIP

You are integrating a module ZIP into the existing Imagine AI Git repository.

## Before editing
1. Inspect the current repository and branch.
2. List the ZIP contents.
3. Read the module README and master project docs.
4. Identify all files that would be added, changed, or conflict.
5. Do not overwrite unrelated or newer files.

## Integration
- Work only on the assigned feature branch.
- Extract/copy only the module-owned files.
- Check import paths, dependency versions, API/schema compatibility.
- Add/adjust tests only within agreed ownership.
- Run documented setup and tests.
- Fix errors in the assigned module; report cross-module problems rather than rewriting other owners' files.
- Keep a change log.

## Final report
- Files added/changed.
- Commands run.
- Exact test results.
- Actual runtime result if executed.
- Issues not resolved.
- Integration assumptions.
- Suggested commit message.

Do not state “working” unless the tests or manual run demonstrate it.
